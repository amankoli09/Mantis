# Changesets

Welcome to Changesets! This directory holds changelog entries generated by `pnpm changeset`.

When making user-facing changes to the public `mantis` package, run:

```bash
pnpm changeset
```

Follow the prompts to specify the bump type (patch, minor, major) and a summary.
During release preparation, `pnpm changeset version` consumes these entries and updates `CHANGELOG.md` and `package.json`.
